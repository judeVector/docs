## Get started in three steps

Start integrating Sendryx into your application and send your first USDC payment.

### Step 1: Create your account and API key

<AccordionGroup>
  <Accordion title="Sign up for Sendryx" icon="user-plus">
    Create your Sendryx account to get started with the API.

    1. Sign up using the [Sign Up endpoint](/api-reference/authentication/signup) or visit our [dashboard](https://app.sendryx.xyz/signup)
    2. Verify your email address using the link sent to your inbox
    3. Log in to receive your access token

    ```http
    POST /auth/login
    Content-Type: application/json
    
    {
      "email": "developer@example.com",
      "password": "SecurePassword123!"
    }
    ```

    <Tip>
      Keep your access token secure - you'll need it to create API keys!
    </Tip>
  </Accordion>
  <Accordion title="Create your API key" icon="key">
    Generate an API key to authenticate your API requests.

    1. Use your access token to call the [Create API Key endpoint](/api-reference/developer-portal/create-api-key):

    ```http
    POST /v1/developer/api-keys
    Authorization: Bearer {access_token}
    Content-Type: application/json
    
    {
      "name": "My Production API Key"
    }
    ```

    2. Save your `keyId` and `secret` Immediately - the secret won't be shown again!
    3. Store your credentials securely using environment variables

    <Warning>
      Never commit your API secret to a version control system. Use environment variables or a secrets manager.
    </Warning>
  </Accordion>
</AccordionGroup>

### Step 2: Make your first API call

<AccordionGroup>
  <Accordion title="Send your first payment" icon="paper-plane">
    Now let's send USDC to a Solana wallet address.

    1. Use your API key to authenticate the request:

    ```http
    POST /v1/payments/send-wallet
    X-Sendryx-Key: pk_live_your_key_id
    X-Sendryx-Secret: sk_live_your_secret
    Content-Type: application/json
    
    {
      "walletAddress": "SolanaWalletAddress...",
      "amount": 10.00,
      "purpose": "Test payment"
    }
    ```

    2. Check the response for transaction details:

    ```json
    {
      "id": "transaction-uuid",
      "status": "completed",
      "amount": 10.00,
      "transactionSignature": "signature_on_solana",
      "completedAt": "2024-01-15T10:30:05Z"
    }
    ```

    <Tip>
      Start with small amounts for testing. Make sure you have sufficient USDC balance in your wallet!
    </Tip>
  </Accordion>
  <Accordion title="Try with cURL" icon="code">
    Here's a complete example using cURL:

    ```bash
    curl -X POST https://api.sendryx.xyz/v1/payments/send-wallet \
      -H "X-Sendryx-Key: pk_live_your_key_id" \
      -H "X-Sendryx-Secret: sk_live_your_secret" \
      -H "Content-Type: application/json" \
      -d '{
        "walletAddress": "SolanaWalletAddress...",
        "amount": 10.00,
        "purpose": "Test payment"
      }'
    ```
  </Accordion>
</AccordionGroup>

</Accordion>
