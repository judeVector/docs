## Key Features

| Feature                | Description                                          |
| :--------------------- | ---------------------------------------------------- |
| **Automated Payroll**  | Schedule and execute recurring crypto payouts        |
| **Role-Based Access**  | Secure controls for Individuals and Businesses       |
| **Fiat Off-Ramp**      | Convert USDC to local currency (NGN, ZAR, KHS, etc.) |
| **Stablecoin Support** | Native **USDC on Solana**                            |
| **Payment Links**      | Shareable links for easy payment collection          |
| **Webhooks**           | Real-time event notifications                        |
